## 1. 案例框架与利率互换兴起背景

> 课件 第 2–4 页 · 讲解从 `00:00` 开始

### 案例整体框架

本案例围绕一笔利率互换展开，分为三个部分：

1. **互换背景和事件介绍**：分析互换交易的需求动因，并介绍该交易的形成过程、阐释利率互换的起源。
2. **交易完整结构和收益测算**：拆解互换交易的具体结构，测算互换后各方的收益。
3. **风险分析和互换意义**：分析交易中的风险及互换的意义。

> 老师在开场中将三部分概括为：①分析互换交易的需求动因；②拆解交易具体结构、测算互换后各方收益；③介绍交易形成过程、阐释利率互换的起源`▶ 00:00`。

### 1980年代初的金融市场背景

利率互换的兴起与当时的宏观经济环境密切相关：

- **70年代两次石油危机**：能源价格大幅上涨，给美国带来高通胀压力。
- **经济陷入“滞胀”**：成本推动型通胀与经济增长放缓并存，企业经营承压。
- **沃尔克紧缩货币政策**：为抑制通胀，1979年美联储主席保罗·沃尔克采取紧缩货币政策，提高市场利率。
- **利率大幅波动**：企业融资成本显著增加，传统的固定、浮动两种融资方式都面临问题。

> 老师强调：1979年美联储为抑制通胀采取紧缩货币政策，市场利率大幅走高，美国经济下行压力增大，企业经营状况恶化，利率互换工具正是在这一背景下应运而生`▶ 00:35`。

### 传统融资方式的困境

企业传统上只能在固定利率融资和浮动利率融资之间二选一，两者各有利弊：

| 融资方式 | 优点 | 问题 |
|---|---|---|
| 固定利率融资 | 锁定未来融资成本 | 当前融资成本高 |
| 浮动利率融资 | 初始成本低 | 面临未来利率上升的风险 |

在利率高企且波动剧烈的环境下，固定利率融资虽能锁定成本，但当下负担较重；浮动利率融资虽然初始成本较低，却要承担利率进一步上行的风险。

### 利率互换兴起的逻辑

不同企业之间存在两方面差异：

- 对利率风险的**承受能力不同**；
- 在不同融资市场中的**比较优势不同**。

正是基于这种差异，企业可以通过**利率互换（Interest Rate Swap）**重新组合融资成本与风险：各方在自己具有优势的市场融资，再通过互换交换利息支付结构，从而既降低融资成本，又获得与自身风险偏好相匹配的利率类型。利率互换由此逐渐兴起。

## 2. Goodrich与Rabobank的融资困境与比较优势

> 课件 第 5–8 页 · 讲解从 `02:19` 开始

### 案例背景：Goodrich 与 Rabobank 的融资困境与比较优势

本案例通过 B.F. Goodrich 与荷兰 Rabobank 之间的融资互换，说明不同主体在不同融资市场上存在**比较优势**，从而可以通过利率互换降低双方融资成本、调整利率风险结构。

#### Goodrich：陷入融资困境的制造企业

**企业背景**
- B.F. Goodrich（古德里奇）是美国老牌橡胶与轮胎制造企业，创立于 1870 年，主营轮胎和化工制品。
- 公司拥有成熟制造能力，在北美工业领域具有较高知名度和较长经营历史。

**1982 年的财务困境**
- 1982 年经济衰退导致公司盈利和现金流下降。
- 信用等级由 BBB 下调至 BBB-，并即将宣布 1982 年亏损。
- 公司迫切需要大量长期资金，以支持企业发展并缓解财务危机。

> **老师强调**：信用评级下调会直接推高企业融资成本；Goodrich 需要长期资金，而不是单纯依赖短期滚动融资`▶ 02:19`。

**融资目标**
- 获得 **1 亿美元固定利率融资**。
- 原因：
  - 固定未来利息支出；
  - 避免市场利率继续上涨带来的风险；
  - 提高财务规划和经营成本的稳定性。

**融资障碍**
- 由于信用评级下降，市场要求更高的风险补偿。
- Goodrich 直接进行固定利率融资的成本约为 **12.5%**，成本过高。
- 老师补充指出，其短期滚动融资成本与交易对手的差距相对较小`▶ 02:19`。

#### Rabobank：具有融资优势但需调整利率结构

**机构背景**
- Rabobank（荷兰拉博银行）成立于 1898 年，是荷兰顶级合作制银行。
- 该银行深耕农业与实体产业金融，风险较低、市场认可度高。
- 课件中提及其长期维持 **AAA 顶级国际信用评级**；老师讲解时表述为长期保持 **AA 级信用评级**。两种表述均强调其信用等级高、融资优势明显。

**融资需求**
- Rabobank 希望借入**美元浮动利率资金**。
- 目的在于匹配自身负债结构，降低利率错配风险。
- 但其直接借入美元浮动资金时，高评级带来的成本优势相对有限。

> **老师强调**：Rabobank 需要的是美元浮动利率融资，以匹配其负债结构、管理利率错配风险`▶ 04:29`。

#### 双方融资成本与比较优势

| 融资主体 | 固定利率融资成本 | 浮动利率融资成本 | 实际融资需求 |
|---|---:|---:|---|
| Goodrich | 12.5% | LIBOR + 0.5% | 固定利率融资 |
| Rabobank | 10.7% | LIBOR + 0.25% | 浮动利率融资 |
| 成本差距 | 1.8% | 0.25% | — |

从表中可以看出：

- 在**固定利率市场**上，Rabobank 比 Goodrich 低 **1.8%**，优势非常明显。
- 在**浮动利率市场**上，Rabobank 仅比 Goodrich 低 **0.25%**，优势较小。
- 因此，Rabobank 在固定利率融资市场具有更强的比较优势。
- Goodrich 虽然整体信用较弱，但在浮动利率市场上与 Rabobank 的成本差距较小。

> **老师强调**：Goodrich 在浮动利率市场融资难度更高、利差更大；Rabobank 则在固定利率市场具有显著优势。双方信用利差和融资需求的差异，构成了后续互换交易的基础`▶ 05:20`。

#### 本章核心结论

- 双方表面上的融资需求与其比较优势并不一致：
  - 需要固定利率资金的 Goodrich，在固定利率市场明显处于劣势；
  - 需要浮动利率资金的 Rabobank，却在固定利率市场拥有更大优势。
- 这种“**融资需求差异 + 融资成本比较优势差异**”使双方有可能通过互换来实现双赢：
  - 各自先进入自身具有比较优势的市场借款；
  - 再通过利率互换交换利息支付结构；
  - 从而降低综合融资成本，并获得各自希望的利率类型。

> **老师强调**：不同企业在不同融资市场具有比较优势，这是利率互换能够产生利益的根本原因。

## 3. 互换交易的撮合、中介介入与合约要素

> 课件 第 9–10 页 · 讲解从 `05:58` 开始

### 互换交易的形成过程

1983年初，Salomon Brothers（所罗门兄弟）担任Goodrich的财务顾问与债券承销商，推动了本次互换方案的形成。

**1. 方案构思**

Goodrich原本计划发行浮动利率票据，然后通过互换交易将浮动利率负债转换为固定利率负债`▶ 05:58`。

**2. 发现比较优势错位**

所罗门兄弟识别出Rabobank与Goodrich在融资市场上存在比较优势错位，于是尝试撮合双方直接进行互换交易。

| | Rabobank | Goodrich |
|---|---|---|
| 评级与成本 | AAA评级，固定融资成本低 | BBB-评级，固定融资昂贵 |
| 融资偏好 | 希望获得浮动利率融资 | 希望转为固定利率负债 |
| 相对优势 | 固定利率融资更有优势 | 浮动利率融资相对更有优势 |

双方的融资需求和成本优势恰好互补，构成了互换的基础：各自在具有比较优势的市场融资，再通过互换交换现金流，从而实现总融资成本的降低。

**3. 交易僵局**

尽管双方需求互补，直接交易却因信用风险问题陷入僵局：

- Rabobank为AAA评级，不愿直接面对评级仅为BBB-的Goodrich；
- 互换合约期限长达8年，Rabobank担忧周期内Goodrich违约会带来大额对手方风险。

**4. 中介介入**

为打破僵局，Morgan Guaranty（摩根担保，讲解中也称摩根大通）作为Swap Bank（互换交易商/互换银行）加入交易：

- 将原本的一笔互换拆分为**两笔独立合约**，分别与Goodrich、Rabobank签约；
- 充当双方的交易对手，互换各自的现金流；
- 承担双方的违约风险，提供信用担保（信用增信），解决了彼此间的信用风险顾虑；
- 作为回报，收取相应的服务费`▶ 05:58`。

这样，Goodrich与Rabobank不再直接面对对方，而是各自只与Morgan Guaranty交易。

### 本笔互换的合约要素

| 要素 | 内容 |
|---|---|
| 交易双方 | Goodrich、Rabobank |
| 中介方 | Morgan Guaranty（互换银行） |
| 交易时间 | 1983年3月7日 |
| 名义本金 | 5000万美元 |
| 交易期限 | 8年 |
| 交易类型 | 利率互换（Interest Rate Swap） |

> **老师强调**：交易期限长达8年，双方存在对手方信用风险顾虑，因此需要摩根担保作为互换交易商介入，将一笔互换拆成两笔独立合约并提供信用担保`▶ 05:58`。

1983年3月7日，两家公司分别完成了5000万美元的8年期融资，为后续互换现金流的交换做好了准备`▶ 07:36`。

## 4. 债券融资与互换现金流结构

> 课件 第 12–15 页 · 讲解从 `08:30` 开始

### 初始融资安排：两笔债券

Goodrich 与 Rabobank 各自在自己有融资优势的市场发行债券，两笔债券的名义金额均为 5000 万美元，期限均为 8 年，但**利率类型和付息频率不同**：

| 发行人 | 发行市场 | 债券利率类型 | 票面利率 | 付息频率 |
|---|---|---|---|---|
| Goodrich | 美国市场 | 浮动利率债券 | LIBOR + 0.5% | 每半年付息一次 |
| Rabobank | 欧洲市场 | 固定利率债券 | 11% | 每年付息一次，每年支付 550 万美元 |

- Goodrich 的利息支出随 LIBOR 波动而调整；Rabobank 每年固定向欧洲债券投资者支付 550 万美元（5000 万 × 11%）`▶ 08:30`。
- 两家公司融资后承担的利率类型与自身需求不匹配，因此需要通过利率互换来调整利率属性`▶ 08:30`。

> **老师强调**：Rabobank 债券实际每年支付的票息为 11%；之前出现的 10.7% 是把年付息口径换算成半年付息口径后的可比收益率，并不代表实际票面利率。11% 年付利率换算为半年付息口径后约为 10.7%`▶ 08:30`。

### 互换结构总览

Morgan Guaranty（摩根担保银行）作为中介，**分别与 Goodrich 和 Rabobank 签署两份互换协议**，而不是由两家公司直接签约`▶ 09:31`。互换分为两层现金流：

- 固定利息腿（Fixed Leg）
- 浮动利息腿（Floating Leg）

互换全程**不交换本金**，5000 万美元只是用于计算利息的名义本金；两笔原始债券继续存续，仍由两家发行人自行向投资者偿付本息`▶ 12:57`。

### 互换现金流（一）：固定利息腿

固定利率为 **11%**，按 5000 万美元名义本金计算，每年金额为：

$$5000\text{万} \times 11\% = 550\text{万美元}$$

固定利息的流向为：

```text
Goodrich ──支付11%（每年550万美元）──▶ Morgan Guaranty ──支付11%──▶ Rabobank
```

- Goodrich 每年向 Morgan 支付 550 万美元固定利息；Morgan 再将等额资金支付给 Rabobank`▶ 09:31`。
- Rabobank 收到 11% 的固定利息后，正好用来支付自身发行的 11% 固定利率债券利息，固定利息实现抵消：

$$\text{Rabobank：互换收到 }11\% - \text{债券支付 }11\% = 0$$

- 原本承担固定利率的 Rabobank，由此把固定利率风险转移出去，转化为承担浮动利率`▶ 09:31`。

### 互换现金流（二）：浮动利息腿

浮动利率为 **LIBOR − x**，其流向与固定利息相反：

```text
Rabobank ──支付 LIBOR−x ──▶ Morgan Guaranty ──支付 LIBOR−x ──▶ Goodrich
```

- Rabobank 向 Morgan 支付 LIBOR − x 的浮动利息，Morgan 再向 Goodrich 支付相同金额的浮动利息`▶ 11:29`。
- 其中 **x 是浮动利率折让（转让幅度）**，是双方分配融资比较优势的调整参数：
  - **x 越大**：Rabobank 支付的浮动利息越少，获得的利率优惠越多；Goodrich 收到的浮动利息越少，实际融资成本越高，意味着 Rabobank 分到的融资优势更多。
  - **x 越小**：Goodrich 收到的浮动利息越多，实际融资成本越低，意味着 Goodrich 分到的融资优势更多`▶ 10:15`。

> **老师强调**：原始案例并未披露 x 的具体数值，课堂测算时假设 x 为 0.2% 或 0.3%`▶ 11:29`。

对 Goodrich 而言，其债券的浮动利息支付与互换中收到的浮动利息轧差：

$$\text{债券支付 }(LIBOR+0.5\%) - \text{互换收到 }(LIBOR-x) = 0.5\% + x$$

LIBOR 部分被抵消，剩下的 0.5% + x 是固定的利差支出；再加上向 Morgan 支付的 11% 固定利息，Goodrich 最终承担的是固定利率融资成本。

> **注意支付频率差异**：Goodrich 的浮动利率债券是每半年付息一次，而互换中的固定利息为每年支付一次，二者支付频率并不相同，实际测算时需统一付息口径`▶ 11:29`。

### 完整交易结构：两层现金流

可以把整个交易拆成上下两层来看：

**第一层：债券融资层（与投资者之间，继续存续）**

- Goodrich → 美国债券投资者：支付 LIBOR + 0.5%（浮动，半年付）
- Rabobank → 欧洲债券投资者：支付 11%（固定，年付 550 万美元）

**第二层：利率互换层（通过 Morgan 进行）**

- 固定腿：Goodrich ──11%──▶ Morgan ──11%──▶ Rabobank
- 浮动腿：Rabobank ──LIBOR−x──▶ Morgan ──LIBOR−x──▶ Goodrich

轧差后双方的最终融资属性发生转换：

| 公司 | 债券层原本承担 | 互换层操作 | 最终承担 |
|---|---|---|---|
| Goodrich | 浮动利率 LIBOR + 0.5% | 支付 11% 固定，收取 LIBOR − x 浮动 | **固定利率**融资成本 |
| Rabobank | 固定利率 11% | 收取 11% 固定，支付 LIBOR − x 浮动 | **浮动利率**融资成本 |

- 对 Goodrich：向投资者支付的 LIBOR + 0.5% 与从 Morgan 收取的 LIBOR − x 轧差抵消浮动部分，再加上支付的 11% 固定利息，最终转为固定利率融资`▶ 12:02`。
- 对 Rabobank：向投资者支付的 11% 固定利息被从 Morgan 收取的 11% 抵消，只需向 Morgan 支付 LIBOR − x，最终转为浮动利率融资`▶ 12:02`。

### Morgan Guaranty 的角色与费用

Morgan 分别与两家公司签订互换协议，处于交易中间，承担双方的**信用风险**（如一方违约，Morgan 仍须对另一方履约），其角色是信用中介`▶ 12:57`。

作为承担信用风险和提供中介服务的补偿：

- Goodrich 向 Morgan 支付 **12.5 万美元的一次性初始费用**；
- 此后还需支付**年度保证费（担保费）**，具体金额课件未列示`▶ 12:57`。

> **老师强调**：互换中本金不交换、仅用于计息；原始债券不注销，仍由两家发行人各自向投资者履行偿付义务，互换只改变双方承担的利率类型（固定与浮动的互换）`▶ 12:57`。

## 5. 三方收益测算与X参数的分配效应

> 课件 第 16–18 页 · 讲解从 `13:22` 开始

### Goodrich（固德里奇）的收益测算

互换后，Goodrich 的全部现金流支出包括四部分：

1. 支付原浮动利率债券利息：**LIBOR + 0.5%**
2. 向 Morgan 支付互换固定利息：**11%**
3. 从 Morgan 收入互换浮动利息：**LIBOR − x**
4. 支付 Morgan 年度保证费：**f**

净融资成本为：

$$
(\text{LIBOR}+0.5\%) + 11\% - (\text{LIBOR}-x) + f
$$

式中两笔 LIBOR 相互抵消，得到：

$$
\text{净成本}=11.5\%+x+f
$$

可见互换后 Goodrich 的融资成本不再含 LIBOR，被**锁定为固定利率**。

代入示例假设 **x = 0.20%，f = 0.10%**：

$$
11.5\%+0.20\%+0.10\%=11.8\%
$$

与直接发行固定债券的参考成本 **12.5%** 相比：

- 每年节省：12.5% − 11.8% = **0.70 个百分点**
- 名义本金 5000 万美元，对应年节省：5000 万 × 0.70% = **35 万美元/年**`▶ 13:22`
- Goodrich 另需支付一次性初始费 **12.5 万美元**，简单摊到 8 年：
  - 年均摊费用：12.5 万 ÷ 8 ≈ 1.56 万美元
  - 年均净节省：35 万 − 1.56 万 ≈ **33.44 万美元/年**`▶ 13:22`

> **老师强调**：11.8% 是互换后的固定融资成本；33.44 万美元是把一次性初始费简单平摊 8 年后的年平均净节省，属于教学测算，未做完整折现。

---

### Rabobank（荷兰合作银行）的收益测算

互换后，Rabobank 的现金流为：

1. 支付原固定债券利息：**11%**
2. 向 Morgan 支付互换浮动利息：**LIBOR − x**
3. 从 Morgan 收入互换固定利息：**11%**

净融资成本为：

$$
11\% + (\text{LIBOR}-x) - 11\%
$$

两笔 **11% 固定利息相互抵消**，得到：

$$
\text{净成本}=\text{LIBOR}-x
$$

代入示例假设 **x = 0.20%**：

$$
\text{净成本}=\text{LIBOR}-0.20\%
$$

与直接发行长期浮动利率债券的参考报价 **LIBOR + 0.25%** 相比：

- 每年节省：(LIBOR + 0.25%) − (LIBOR − 0.20%) = **0.45 个百分点**
- 名义本金 5000 万美元，对应年节省：5000 万 × 0.45% = **22.5 万美元/年**`▶ 14:56`

> **老师强调**：Rabobank 的节省必须以“直接发行长期浮动利率债券”的参考报价 LIBOR + 0.25% 作为比较对象；其互换后结果是获得更低成本的长期浮动利率融资。

---

### 参数 x 的分配效应

在本交易中，**x 并不改变两家公司节省总额，只改变节省在 Goodrich 与 Rabobank 之间的分配**。

| 参数变化 | 对 Goodrich 的影响 | 对 Rabobank 的影响 |
|---|---|---|
| x 上升 | 净成本 `11.5% + x + f` 上升，节省减少 | 净成本 `LIBOR − x` 下降，节省增加 |
| x 下降 | 净成本下降，节省增加 | 净成本上升，节省减少 |
| x 变动 0.10 个百分点 | 年节省金额反向变动 5 万美元 | 年节省金额同向变动 5 万美元 |

以本金 5000 万美元计算：

$$
5000\text{万}\times 0.10\%=5\text{万美元}
$$

因此，x 每变动 0.10 个百分点：

- Goodrich 的年节省金额变动 **5 万美元**；
- Rabobank 的年节省金额按相反方向变动 **5 万美元**；
- 两家公司的**总节省金额保持不变**。`▶ 15:45`

> **老师强调**：x 是收益分配参数。x 上升意味着互换浮动利率 `LIBOR − x` 降低：Goodrich 收到的浮动利息减少，所以成本上升；Rabobank 支付的浮动利息减少，所以成本下降。双方利益一增一减，总额不变。

---

### 三方收益汇总

在统一假设 **x = 0.20%、f = 0.10%、名义本金 = 5000 万美元** 下，三方结果如下：

| 参与方 | 互换后融资结果 | 年度收益或成本节省 | 主要角色与风险 |
|---|---|---:|---|
| **Goodrich** | 固定利率融资，净成本 **11.8%** | 未摊初始费时节省 **35 万美元/年**；摊入 12.5 万美元初始费后年均净节省约 **33.44 万美元** | 将原浮动债务转换为长期固定利率债务 |
| **Rabobank** | 浮动利率融资，净成本 **LIBOR − 0.20%** | **22.5 万美元/年** | 将原固定债务转换为长期浮动利率债务 |
| **Morgan** | 不直接承担最终融资需求 | 年度保证费：5000 万 × 0.10% = **5 万美元/年**；另收一次性初始费 **12.5 万美元** | 提供互换信用中介服务，并承担互换对手方信用风险 |

需要注意：

- Goodrich 支付的 **12.5 万美元初始费**，就是 Morgan 收取的同额初始费；
- Morgan 收取的保证费和初始费属于**收费收入**，并不等于净利润，因为它还要承担相应信用风险；
- 表中节省金额均为教学假设下的简单测算，**尚未进行完整折现或风险调整**。`▶ 16:15`

### 本章结论

该互换交易依托双方在不同融资市场上的**比较优势**：Goodrich 和 Rabobank 先各自发挥融资优势，再通过 Morgan 安排现金流互换，使 Goodrich 获得长期固定利率资金、Rabobank 获得长期浮动利率资金，同时降低整体融资成本。参数 x 决定互换收益在两家公司之间的分配，参数 f 则体现 Morgan 提供信用中介和承担信用风险所获得的补偿。

## 6. 互换后的信用风险与残余风险

> 课件 第 19–21 页 · 讲解从 `17:19` 开始

### 互换完成后，风险真的消失了吗？

互换达成后，交易双方虽然实现了融资成本降低、融资结构（固定/浮动属性）匹配的目标，但风险并没有被完全消除，而是从直观的利率波动风险，转化为需要精细化识别和管理的一系列风险，主要包括信用风险（交易对手风险）和互换后的残余风险`▶ 17:19 · 19:22`。

### 信用风险与重置成本（Counterparty Risk）

互换本身不交换本金，但互换合同作为一份存续的衍生品合约，其自身具有价值，并且价值会随市场利率变动而变化。

以 Goodrich 与 Morgan（摩根）的互换为例：
- Goodrich 向 Morgan **支付固定利率**；
- Morgan 向 Goodrich **支付浮动利率**。

当市场上的互换固定利率下降时，Morgan 原先持有的"收取较高固定利息"的头寸变得更有价值（合同对 Morgan 呈现正向市值）。此时若 Goodrich 违约，Morgan 必须重新进入市场寻找新的交易对手来重置这份合同，而新合同只能按更低的市场固定利率签约，新旧合同之间的差额就是信用风险造成的损失，即互换的**重置成本**`▶ 17:48`。

> **老师强调**：计算互换的信用风险时，不能只看名义本金或某一期利息，而要评估整个互换合同的当前市场价值（未来各期现金流差额的现值）`▶ 17:48`。

教学用测算示例（**非1983年历史成交数据，也非实际损失**）：

| 参数 | 含义 | 取值 |
|---|---|---|
| N | 名义本金 | 5,000 万美元 |
| A | 未来现金流折算系数（约等于年数调整） | 5 |
| K | 原互换合同的固定利率 | 10.7% |
| S | 下降后的市场互换固定利率 | 9.9% |

合同正向市值近似为：

$$
V \approx N \times A \times (K - S) = 5{,}000\text{万} \times 5 \times (10.7\% - 9.9\%)
$$

- 合同正向市值（潜在重置损失）：约 **200 万美元**（即 5,000 万 × 0.8% × 5）`▶ 17:48`；
- 减去已持有的担保品：160 万美元；
- **未担保敞口约 40 万美元**。

这说明即使有担保品安排，当合同市值上涨超过担保品价值时，守约方仍会承担一部分无担保的交易对手敞口。

### 互换之后的残余风险（Residual Risks）

Goodrich 通过互换，原本面临的 **LIBOR 上行风险已大体对冲**，其浮动利率融资被转换为实质上的固定利率融资`▶ 19:09`。但互换只能"大部分抵消"债券端利率波动引起的现金流变化，完全抵消的前提是互换两端的现金流严格匹配；一旦匹配条件不满足，就会留下以下残余风险`▶ 19:22`：

**1. 基差风险与重置风险**
- 当互换两端的参考基准利率不一致、利率重置日不同，或付息频率不匹配时，浮息现金流的抵消可能不完全，由此产生基差风险`▶ 19:22`。
- 例如债券端盯住某一浮动基准、互换端盯住 LIBOR，两个基准走势出现偏离时，就会留下无法对冲的缺口。

**2. 提前终止与流动性风险**
- 若需要提前解除互换合约，必须按当时市值进行结算，可能产生终止费用`▶ 19:22`。
- 终止付款或追加保证金都会形成即时的现金需求，带来流动性压力。

**3. 交易对手风险**
- 当合同对己方具有正向重置价值时，一旦对手违约，己方可能丧失这部分正价值，即前面所述的重置成本损失（如示例中扣除担保品后仍有约 40 万美元敞口）。

**4. 模型、合同与治理风险**
- 合同条款的理解偏差、估值模型出错、压力情景考虑不足，以及内部授权问题，都会影响风险能否被及时识别和管理`▶ 19:22`。

> **老师强调**：互换并没有把风险彻底消除，而是把原本直观的"利率上涨风险"，转化为基差风险、流动性风险、交易对手风险、模型与合同治理风险等需要精细化管理的细分风险`▶ 19:22`。

## 7. 中介信用、风险治理与市场制度演进

> 课件 第 22–25 页 · 讲解从 `20:14` 开始

### 从中介信用到现代风险治理体系

早期互换交易高度依赖中介机构的信用。以固特异—拉博银行（Goodrich–Rabobank）案例为例，拉博银行原本不愿直接与固特异开展期限长达8年的利率互换；摩根大通将一笔双方之间的互换拆分为两笔双边合约，分别与固特异、拉博银行签约，以自身信用隔离双方的交易对手风险，同时也承担了双方违约的风险`▶ 20:14`。因此，1983年的交易主要依靠中间银行的信用背书。

现代场外衍生品市场则不再单纯依赖中介信用，而是由标准化合同、担保品、中央清算和监管报告等制度共同支持。但这些安排只能降低、分散或转移风险，并不意味着风险完全归零`▶ 20:55`。

| 风险治理机制 | 主要内容 | 作用与局限 |
|---|---|---|
| 标准合同 | ISDA主协议，约定终止条款与净额结算规则 | 明确双方权利义务，降低合同不确定性；违约终止时可通过净额结算减少风险敞口 |
| 担保品 | 盯市与保证金 | 降低未担保信用敞口；但保证金调用会带来资金占用和流动性需求 |
| 中央清算 | 符合条件的交易由CCP承接履约安排 | CCP成为交易双方的共同对手方，提升履约保障；但风险可能向CCP集中，仍需管理集中度风险 |
| 交易报告 | 信息报送与审慎监管 | 提高市场透明度，使监管机构能够监测风险积累 |

> **老师强调**：现代市场是在中介信用之外，叠加了标准化合同、担保品、中央清算和监管等多重机制；但风险治理机制完善，并不代表风险完全消失`▶ 20:55`。

### 互换市场案例与制度演进

互换市场的发展可以通过几个标志性案例和制度变化来理解。

| 时间 | 事件 | 意义 |
|---|---|---|
| 1981年 | IBM—世界银行货币互换 | 早期代表性互换交易，帮助主体拓展融资渠道、管理不同货币的融资条件 |
| 1983年 | 固特异—拉博银行利率互换，由摩根大通中介 | 将浮动利率风险转换为固定利率风险，体现中介信用在早期市场中的核心作用 |
| 1993—1996年 | 宝洁—信孚银行杠杆互换争议 | 1993年签约，1994年起诉，1996年和解；推动市场重视复杂衍生品的结构风险与适当性问题 |
| 2009年 | G20推动场外衍生品市场改革 | 强化交易报告、中央清算以及非集中清算交易的风险管理 |
| 2023—2025年 | 美元LIBOR退出，SOFR与OIS发展 | 2023年6月30日美元LIBOR银行报价机制结束，SOFR成为美元利率市场主要基准，OIS交易活跃 |

> **注意**：课堂上把1981年IBM—世界银行交易称为首笔利率互换，但课件表述为“货币互换”。按课件知识结构，该交易对应的是早期货币互换安排。

宝洁案中，1993年交易达成，1994年引发诉讼，1996年双方和解。和解本身不能等同于法院作出“欺诈成立”的终局判决；但该事件显著提高了市场对复杂、杠杆型衍生品风险的关注`▶ 21:12`。

### 两类利率互换案例的风险结构对照

固特异案与宝洁案都涉及利率互换，但交易目的、现金流结构和风险结果明显不同。

| 比较维度 | 固特异—拉博银行 | 宝洁—信孚银行 |
|---|---|---|
| 现金流结构 | 原始负债为浮动利率债务；通过互换“收浮动、付固定” | 付款利差挂钩国债收益率与债券价格等变量，并含杠杆条款 |
| 风险结果 | 原始负债的浮动利息与互换收到的浮动利息大致抵消，从而锁定融资成本 | 杠杆放大市场利率变动对合约价值的影响，小幅波动可能造成大幅盈亏 |
| 判断依据 | 互换现金流是否与原始负债相匹配 | 是否核对付款公式、进行压力情景分析并建立治理机制 |
| 核心问题 | 用结构匹配的互换管理融资利率风险 | 主体能否理解并承受复杂公式和杠杆带来的现金流波动 |

在固特异案例中，企业原本承担浮动利率负债，再通过互换支付固定利率、收取浮动利率；两端浮动现金流大致抵消，相当于为融资成本增加一层保险，从而把综合融资成本转换为接近固定的水平`▶ 22:01`。

宝洁1993年的互换则复杂得多：付款金额不仅与普通短期利率有关，还与美国5年期、30年期国债收益率挂钩，并带有杠杆。市场利率的小幅变化可能导致合约价值大幅变化，因此交易仅一年后就引发诉讼`▶ 22:01`。

> **老师强调**：两类案例的核心区别不在于“互换合同本身好或坏”，而在于交易主体是否真正理解付款公式，是否能够承受对应的现金流波动，并具备相应的风险治理能力`▶ 22:01`。

### 基准利率与现代市场结构变化

与1983年相比，当前互换市场主要有两方面变化：

1. **基准利率变化**：固特异交易时代广泛使用的LIBOR已经退出；美元利率市场转向以SOFR为主要基准，并推动与SOFR相关的OIS等产品发展`▶ 23:13`。
2. **市场制度变化**：中央清算、保证金、交易报告和监管规则比1983年更加完善，风险治理从依赖单一中介信用转向多层次制度安排`▶ 23:13`。

根据国际清算银行（BIS）2025年4月的调查，全球场外利率衍生品成交额结构如下：

| 产品类别 | 成交额占比 |
|---|---:|
| OIS（隔夜指数互换） | 65% |
| 其他IRS（利率互换） | 24% |
| 其他IRD（利率衍生品） | 11% |

- 表中比例经四舍五入处理。
- 统计口径是**成交额**，不是未偿名义本金余额。
- OIS占比达到65%，反映出新基准利率体系下隔夜指数互换的活跃度显著上升`▶ 23:13`。

尽管风险管理工具、清算机制和基准利率都在迭代，互换用于管理利率风险、转换现金流属性的核心逻辑并未改变：关键仍在于衍生品现金流是否与基础风险相匹配，以及交易主体能否理解并承担合同产生的风险`▶ 23:13`。

## 8. 金融工程意义与全课总结

> 课件 第 26–28 页 · 讲解从 `24:23` 开始

### 金融工程的核心意义：融资与风险的分离

本案例（Goodrich–Rabobank 利率互换）揭示了金融工程最核心的思想之一：**融资来源与最终承担的利率风险可以相互分离**。企业选择以何种形式融资，并不决定它最终必须承担何种利率风险，互换等衍生品可以在资产负债表层面重新配置风险`▶ 24:23`。

#### 三个关键认识

**1. 融资形式改变后，风险仍可重新配置**

以 Goodrich 为例，它先在市场上借入浮动利率债务，再通过互换（收浮动、付固定）锁定融资成本，最终把浮动利率负债转化为固定成本负债。融资工具本身没有变，但企业实际承担的风险敞口被重新安排了`▶ 24:23`。

> **老师强调**：评价一笔互换不能只看当期节省了多少利息，必须核对企业的**原始风险**，同时考虑信用风险、极端情景、提前终止成本以及保证金占用等因素`▶ 24:23`。

**2. 对冲不是无成本获利**

互换表面上让交易双方都"省下了融资成本"，但省下的利息需要抵补以下成本：

- **信用风险**：交易对手违约的风险；
- **提前退出成本（终止成本）**：在合约到期前终止互换可能产生的代价；
- **保证金占用**：为履约而缴存保证金所带来的资金成本。

因此，不能因为双方都省钱就简单判定交易一定划算`▶ 24:23`。

**3. 服务整个资产负债表（ALM，资产负债管理）**

互换不仅服务单笔融资，还能服务整张资产负债表。Rabobank 的情形是典型例子：

| 项目 | 特征 |
|---|---|
| 资产端 | 多为浮动利率贷款（浮动资产） |
| 负债端 | 多为固定利率债券（固定负债） |
| 互换操作 | 收固定、付浮动 |
| 合成结果 | 把固定负债**合成**为浮动负债 |

经过互换，负债端的利率重置特征与浮动资产端更加匹配，资产与负债的利率波动趋于同步，从而实现对冲利率风险的效果`▶ 24:23`。

### Goodrich–Rabobank 案例的总结：金融工程重新安排风险

综合全课，金融工程的作用是**识别、定价并管理风险**，围绕这一核心可归纳出三点：

- **融资与风险分离**：融资方式与风险承担可以脱钩，互换灵活地重新配置风险；
- **复杂条款需要治理**：衍生品结构越复杂，潜在风险越高；
- **交易创新需要制度支持**：金融创新离不开相应的市场规则与基础设施`▶ 25:36`。

> **老师强调**：互换从来不会让风险凭空消失，而是帮助市场主体**重新安排、识别与管理风险**——这是互换最核心的意义`▶ 25:36`。

#### 与宝洁案的对照

- **固特异（Goodrich）案例**：正面展示互换如何灵活调整融资成本与风险，运行顺畅、没有跌宕剧情，完整呈现了互换的运作流程、潜在风险以及金融机构的撮合设计作用`▶ 25:36`[29]。
- **宝洁（P&G）案例**：反面警示——复杂衍生品的潜在风险更高，交易可能从常规对冲演变为诉讼纠纷`▶ 25:36`。

后续建立的**中央清算机制**和**基准利率改革（如 LIBOR 过渡）**，正是为金融创新和衍生品交易制定规则、提供制度支持的体现`▶ 25:36`[28]。

#### 对互换产品本身的定位

- 本课介绍的两类基础互换，结合 Bank of America 案例，既揭示了互换实际运行中的风险，也说明了产品落地背后复杂的制度设计`▶ 26:18`。
- 互换结构相对简单，出错概率低于其他更复杂的金融产品`▶ 26:18`。

### 金融交易与金融机构的价值

老师以一位非金融专业出身、从事衍生品交易的朋友为例：这位朋友长期困惑自身工作的价值。老师的解答是：

> 只要依法依规参与市场交易，无论主观初衷是盈利还是投机，所有金融交易本质上都在完成市场的**价值发现**；金融机构在交易撮合过程中也承担了这一作用，这正是金融在整个经济体中的角色与含义之一`▶ 29:00`[29]。

## 9. 案例复习重点与比较优势、信用风险补充

> 课件 第 8–22 页 · 讲解从 `30:11` 开始

### 一、案例复习重点

本案例的交易主体为 **Goodrich（古德里奇）公司**与 **Rabobank（荷兰合作银行/拉威银行）**，中介机构为 **Morgan Guaranty**。复习时应重点把握三方面：

1. **20世纪80年代互换市场活跃的宏观背景**；
2. **两家企业的融资环境、融资需求及比较优势匹配逻辑**；
3. **金融机构在互换合约达成与运行中的作用**`▶ 30:11`。

> **老师强调**：要掌握互换中的比较优势，明确双方比较优势的具体内容和来源；同时理解互换收益并非“无风险收益”，其核心风险是信用风险`▶ 31:24 · 32:12`。

---

### 二、双方融资条件与比较优势

双方在固定利率和浮动利率市场的融资成本如下：

| 融资方式 | Goodrich | Rabobank | 利差 |
|---|---:|---:|---:|
| 固定利率融资 | 12.5% | 10.7% | 1.8% |
| 浮动利率融资 | LIBOR + 0.5% | LIBOR + 0.25% | 0.25% |
| 实际融资需求 | 固定利率融资 | 浮动利率融资 | — |

Rabobank在两个市场上的融资成本都低于Goodrich，因此在固定和浮动利率借贷方面均具有**绝对优势**。但双方在两个市场上的利差并不相同：

- 固定利率市场利差：**1.8%**
- 浮动利率市场利差：**0.25%**

因此：

- **Rabobank在固定利率市场具有比较优势**：其固定融资成本更低，优势更明显；
- **Goodrich在浮动利率市场具有相对比较优势**：虽然其绝对成本仍较高，但在浮动利率市场上与Rabobank的差距较小。

双方若都在自己具有比较优势的市场融资，再通过利率互换交换现金流，就可能同时降低融资成本，并获得各自希望的利率类型。

#### 比较优势的来源

比较优势和信用风险来源于固定利率市场与浮动利率市场合约性质的差异，两个市场上的借贷利差并不相等`▶ 32:56`。

- **固定利率债务**：在整个贷款期限内利率完全固定，属于长期融资安排`▶ 33:41`。
- **浮动利率债务**：通常具有“短债长借”的特点，每一期付息后都会重新评估并确定下一期利率`▶ 33:41`。

例如，浮动利率第一期可能为LIBOR + 0.5%；如果企业之后信用等级下降，后续利率可能被调整为LIBOR + 1%甚至更高，融资成本会随企业信用状况动态变化`▶ 34:18`。

信用等级越高的机构通常在固定利率市场越有优势。信用等级较低的企业借款期限越长，违约概率上升越快，因此固定利率市场上的利差属于**长期利差**；浮动利率市场上的利差则属于**短期利差**，通常小于固定利率利差`▶ 34:18`。

> **老师强调**：低信用风险公司通过互换得到的“固定利率”并非绝对没有风险，其融资成本仍可能随自身未来信用状况变化；高信用风险公司即使通过互换得到更低的浮动利率，也要承担交易对手违约风险`▶ 35:25`。

### 三、互换交易的形成过程

#### 1. 时间与参与方

- **交易时间**：1983年3月7日
- **交易双方**：Goodrich、Rabobank
- **中介方**：Morgan Guaranty
- **名义本金**：5000万美元
- **交易期限**：8年
- **交易类型**：利率互换

1983年初，Salomon Brothers（所罗门兄弟）担任Goodrich的财务顾问和债券承销商，提出让Goodrich发行浮动利率票据，再通过互换转换为固定利率负债。

#### 2. 双方的互补性

- **Goodrich**：
  - 直接进行固定利率融资较贵；
  - 浮动利率融资相对更有优势；
  - 实际希望获得固定利率融资。
- **Rabobank**：
  - 固定利率融资成本较低；
  - 实际希望获得浮动利率融资。

所罗门兄弟识别出双方比较优势错位，尝试撮合双方直接进行互换。

#### 3. 直接交易的僵局

Rabobank为AAA评级，而Goodrich评级较低（BBB-）。Rabobank不愿意直接面对Goodrich，原因包括：

- 双方信用等级差距较大；
- 互换合约期限长达8年；
- 担心Goodrich违约造成较大的对手方风险。

#### 4. Morgan Guaranty作为互换银行加入

Morgan Guaranty以Swap Bank的身份加入交易：

- 将一笔互换拆分为Morgan与Goodrich、Morgan与Rabobank的**两笔独立合约**；
- 由Morgan承担双方的违约风险；
- 为交易提供信用增信；
- 收取初始费用和年度保证费。

因此，金融中介的制度设计降低了交易双方直接匹配的困难，增进了市场效率和双方收益，但中介承担风险并取得相应报酬。

---

### 四、初始融资安排

双方均融资5000万美元，期限均为8年。

| 主体 | 发行市场 | 债券类型 | 融资利率 | 付息安排 |
|---|---|---|---|---|
| Goodrich | 美国市场 | 浮动利率债券 | LIBOR + 0.5% | 每半年支付利息 |
| Rabobank | 欧洲市场 | 固定利率债券 | 11% | 每年支付550万美元 |

需要注意：Rabobank债券实际每年支付的票息为11%；前面比较表中的10.7%是换算后的可比收益率。

---

### 五、互换现金流结构

利率互换中不交换本金，只交换利息现金流。两笔原债券继续存续。

#### 1. 固定利息现金流

固定利率为 **11%**，即每年550万美元。

- Goodrich向Morgan支付11%；
- Morgan向Rabobank支付11%。

对Rabobank而言：

```text
互换收到11% - 债券支付11% = 0
```

因此，Rabobank原本支付的11%固定债券利息被互换中收到的11%固定利息抵消。

#### 2. 浮动利息现金流

浮动利率表示为：

```text
LIBOR − x
```

其中，`x`代表浮动利率折让，原案例未披露具体数值。

- Rabobank向Morgan支付LIBOR − x；
- Morgan向Goodrich支付LIBOR − x。

对Goodrich而言，其原债券成本为LIBOR + 0.5%，同时从互换中收到LIBOR − x，因此浮动利率部分抵消后的剩余成本为：

```text
(LIBOR + 0.5%) − (LIBOR − x) = 0.5% + x
```

#### 3. 完整现金流关系

- **Goodrich**：
  - 对外支付浮动债券利息：LIBOR + 0.5%；
  - 向Morgan支付固定利息：11%；
  - 从Morgan收到浮动利息：LIBOR − x；
  - 最终承担固定利率。
- **Rabobank**：
  - 对外支付固定债券利息：11%；
  - 向Morgan支付浮动利息：LIBOR − x；
  - 从Morgan收到固定利息：11%；
  - 最终承担浮动利率。
- **Morgan Guaranty**：
  - 分别与双方签约；
  - 充当信用中介；
  - 承担双方违约风险；
  - 收取初始费和年度保证费。

### 六、收益测算

以下采用课件中的教学示例假设：

```text
x = 0.20%
f = 0.10%
名义本金 = 5000万美元
```

其中，`f`为Goodrich支付给Morgan的年度保证费率。

#### 1. Goodrich的最终融资成本

Goodrich的现金流为：

```text
支付原债券利息 + 互换固定利息 - 互换浮动收入 + 保证费
= (LIBOR + 0.5%) + 11% − (LIBOR − x) + f
```

LIBOR相互抵消：

```text
= 11% + 0.5% + x + f
= 11.5% + x + f
```

代入示例：

```text
= 11.5% + 0.20% + 0.10%
= 11.8%
```

与直接发行固定债券12.5%相比：

```text
12.5% − 11.8% = 0.70%
```

即每年节省0.70个百分点：

```text
5000万美元 × 0.70% = 35万美元/年
```

此外，Goodrich还支付12.5万美元初始费。若简单分摊到8年：

```text
35万美元 − 12.5万美元 ÷ 8 ≈ 33.44万美元/年
```

#### 2. Rabobank的最终融资成本

Rabobank的现金流为：

```text
支付原债券固定利息 + 互换浮动利息 - 互换固定收入
= 11% + (LIBOR − x) − 11%
```

两笔11%固定利息抵消：

```text
= LIBOR − x
```

代入`x = 0.20%`：

```text
= LIBOR − 0.20%
```

与其直接发行长期浮动债券的参考报价LIBOR + 0.25%相比：

```text
(LIBOR + 0.25%) − (LIBOR − 0.20%) = 0.45%
```

即每年节省0.45个百分点：

```text
5000万美元 × 0.45% = 22.5万美元/年
```

#### 3. 三方收益汇总

| 参与方 | 示例收益/成本节约 | 作用或结果 |
|---|---:|---|
| Goodrich | 35万美元/年 | 降低融资成本，锁定长期固定利率 |
| Rabobank | 22.5万美元/年 | 降低融资成本，获得长期浮动利率融资 |
| Morgan | 5万美元/年保证费收入 | 提供互换信用中介服务并承担信用风险 |

补充说明：

- Goodrich另支付12.5万美元初始费，Morgan收到同额初始费；
- Morgan收取的费用不等于净利润，因为其承担了信用风险和相应运营成本；
- 上述节省金额属于教学假设测算，尚未进行完整折现或风险调整。

> **老师强调**：金融市场不存在无风险收益，超过无风险收益的部分必然对应某种风险，互换中最核心的是信用风险`▶ 32:12`。

### 七、互换后的信用风险与重置成本

互换完成并不意味着风险完全消失。利率风险可以通过互换转换或对冲，但交易对手风险仍然存在。

以Goodrich与Morgan之间的互换为例：

- Goodrich向Morgan支付固定利率；
- Morgan向Goodrich支付浮动利率。

如果市场互换固定利率下降，那么Morgan原先收取的较高固定利率就更有价值，该互换对Morgan形成**正向市值**。此时若Goodrich违约，Morgan可能丧失这部分正的重置价值。

课件采用教学假设：

```text
名义本金 N = 5000万美元
剩余年限 A = 5年
原固定利率 K = 10.7%
当前市场固定利率 S = 9.9%
```

近似估值为：

```text
V ≈ N × A × (K − S)
  = 5000万美元 × 5 × (10.7% − 9.9%)
  = 5000万美元 × 5 × 0.8%
  = 200万美元
```

即该合约对Morgan约有200万美元正向市值。

若担保品价值为160万美元，则未担保敞口约为：

```text
200万美元 − 160万美元 = 40万美元
```

这说明担保品可以降低风险，但如果合约市值超过担保品价值，仍存在未担保信用风险。

---

### 八、互换之后的残余风险

#### 1. 基差与重置风险

Goodrich的LIBOR上行风险已经大体对冲，但如果浮动端的基准利率、重置日或付息频率不一致，浮动利息可能无法完全抵消，从而产生基差风险。

#### 2. 提前终止与流动性风险

提前解除互换通常需要按市值结算。若一方处于负市值位置，可能需要支付终止款；担保品或保证金安排也可能形成额外现金需求。

#### 3. 交易对手风险

当合约对一方具有正向重置价值时，如果对手方违约，守约方可能丧失该部分价值。即使有担保品，也可能存在担保品不足或价值波动的问题。

#### 4. 模型、合同与治理风险

互换条款理解、压力情景设定、内部授权和风险管理流程，都会影响风险能否被及时识别和管理。

---

### 九、从Morgan中介到现代风险治理体系

1983年的案例主要依赖Morgan的中介信用。现代互换市场则通过标准合同、担保品、中央清算和交易报告等制度共同支持。

| 治理机制 | 主要内容 | 作用与局限 |
|---|---|---|
| 标准合同 | ISDA主协议，约定终止条款与净额结算规则 | 降低合同不确定性，明确违约和结算安排 |
| 担保品 | 盯市与保证金制度 | 降低未担保敞口，但也会带来资金占用和流动性需求 |
| 中央清算 | 符合条件的交易由CCP承接履约安排 | 降低双边对手方风险，但需关注CCP集中度风险 |
| 交易报告 | 向交易数据库和监管机构报告 | 提高市场透明度，支持风险监测和审慎监管 |

总体来看，互换通过比较优势提高了融资效率，使双方获得更符合需求的利率结构并降低成本；但这种收益伴随着信用风险、基差风险、流动性风险和合同治理风险，需要金融中介、担保品、清算和监管制度共同管理。

## 10. 互换思想在宏观风险分散中的延伸应用

> 讲解从 `37:11` 开始

### 核心思想：用互换应对宏观层面的风险集中问题

互换不仅存在于金融机构之间，还可以延伸到宏观层面，用来解决国家层面的风险分散问题。这一思路来自2018年一场由华人主导的国际金融学术会议演讲，题目为《利用金融应对国际挑战》。其核心是：

> **将风险与资金、投资与治理相互分离**——在不改变资金实际投向和现有制度的前提下，单独把"风险敞口（收益）"通过互换转移出去，从而实现改善政策的目标。`▶ 37:11`

### 应用场景：被迫100%投资本国市场的机构资金

典型对象是主权财富基金、养老金等。这类基金按制度要求必须把资金**100%投资于本国市场**。例如中国某主权财富基金全部投资中国A股，其收益就完全绑定本国股市，风险高度集中。`▶ 38:25`

现实中投资者也普遍存在两种"本土偏好"倾向：
- 投资本土股票；
- 投资自家公司股票。

其中投资自家公司股票从风险分散角度看是**不理性的**——投资者的人力资本（工资收入）已经依赖这家公司，再持有其股票，本质上是在为公司经营状况加倍下注。但上述100%投本国的要求是现行制度的硬性规定，问题在于：**如何在不违反制度的前提下分散风险？**`▶ 38:25`

### 解决方案：总收益互换（Total Return Swap）

设计一份总收益互换合约：

| 方向 | 内容 |
|---|---|
| 支付 | 中国A股的收益率 |
| 收取 | 世界股票（全球市场）的收益率 |

这样，基金在**法律和账面上仍然100%持有中国股票**，满足政策要求；但在经济实质上，最终收益等于世界股票的收益率，不再仅绑定中国A股，实现了收益的全球多元化。`▶ 40:07`

**现金流的双向调节效应：**
- 中国市场表现**好于**国际市场时：基金需向对手支付差额 → 现金**流出**；
- 中国市场表现**差于**国际市场时：对手向基金支付差额 → 现金**流入**。

这种"差时补入、好时补出"的机制自然对冲了市场下行风险。同时对交易对手而言，可以在低信用成本、合规的前提下便捷参与中国A股，无需受QFII等境外投资额度限制，也有助于调节中国市场的资产泡沫。`▶ 41:04`

### 该设计的具体优势

1. **降低资金成本、提升股价**：全球投资者共同分担中国资产风险后，中国企业的资本成本下降，股票价值被推高。`▶ 42:04`
2. **对接全球长期投资者**：可引入指数基金、金融机构核心资产持有者等。这类投资者通常不做短期择时，是稳定的长期持有人。`▶ 42:04`
3. **信用风险很低**：
   - 互换的本金（名义本金）不交换、无风险；
   - 可灵活设置付息频率，如0.25年、半年、一年，选择自身现金流充裕的时段结算；
   - 交易双方信用等级都很高，可将道德风险与未回收损失降到最低；
   - 还能规避税务、会计规则变更带来的大幅影响。`▶ 42:04`

### 具体执行的机构安排

- **对接层面**：可由外国的主权财富基金、政府养老基金、储备基金、中央银行，直接对接中国政府机构，如国家外汇管理局（SAFE）、中国投资有限责任公司（中投公司）。`▶ 43:54`
- **国内层面**：中国社保基金（MSS）可与外国主权财富基金、国内高信用等级机构直接开展互换。由于双方信用极高，交易执行成本低，无需高等级信用中介撮合，也不必担心对手违约。`▶ 44:37`
- **向散户延伸**：中国相关机构还可与当地银行、保险公司、资产管理公司开展同类全球收益互换，进一步把分散化的收益分配给散户投资者，提升市场公平性。`▶ 45:18`

### 宏观作用：抑制本地资产泡沫

这类交易能降低本地资产泡沫造成的扭曲与风险，做法是为本地股票、房地产等资产提供"全球投资替代选项"。`▶ 45:37`

资产泡沫形成有两个核心原因：
1. **一致性乐观信念无法被市场充分吸收**：悲观投资者没有渠道表达观点，市场价格只反映了乐观预期；
2. **投资标的过于集中**：投资者没有其他选择，即使本地资产风险偏高也只能投本地。

当投资资产来源更加多元时，资金不必涌入单一本地资产，本地资产泡沫就会降低。`▶ 45:37`

### 制度与政策上的优点

- **无需修改现有金融体系设计和监管政策**；
- **政策可逆**：如需调整，可通过对冲式互换或其他金融工具进行反向操作，不必撤销原有合约重新开展；
- 适用性强，不受本地金融系统具体设计的影响。`▶ 47:03`

> **老师强调的核心逻辑**：把**风险流、资本流与投资治理**分离开，就能通过金融创新在不动制度的情况下落实政策目标，避免低效率风险分散所带来的额外成本。`▶ 47:37`

### 延伸：金融创新改善政策的成熟案例——天气衍生品

金融创新落地已有成熟先例。农业自然灾害多，原有风险保障主要靠政策性保险，但这类保险往往**收益无法覆盖成本**，且需要事后核定损失再赔付（例如甘肃夏季冰雹损毁烤烟，最终靠政策性保险赔付）。`▶ 48:05`

作为补充，大型农户可通过交易与**积雨、冰雹、降雨**相关的天气衍生品来对冲风险，这类工具基于客观气象数据结算，比保险更直接。总体而言，好的金融创新思路能够有效改善政策目标的实现。`▶ 48:05`

> **本章小结**：互换的精髓在于"分离"——资金照旧投向本国资产以满足合规，而通过总收益互换把收益（风险）换成全球组合，既分散了宏观风险、抑制了本地泡沫，又保持了低成本、低信用风险和政策可逆性，是金融工程服务宏观政策的典型思路。

## 术语

| 术语 | 解释 |
| --- | --- |
| 利率互换 | 交易双方约定在相同名义本金基础上交换固定利率与浮动利率现金流，通常不交换本金。 |
| 比较优势 | 不同信用等级主体在固定利率和浮动利率融资市场上的利差不同，从而可通过互换分享相对融资优势。 |
| 名义本金 | 互换中仅用于计算利息支付的本金金额，本案为5000万美元，互换双方并不实际交换该本金。 |
| 固定端现金流 | Goodrich向Morgan支付11%固定利息，Morgan再将等额固定利息支付给Rabobank。 |
| 浮动端现金流 | Rabobank支付LIBOR-X，Morgan再向Goodrich支付LIBOR-X，用以抵消Goodrich债券端的浮动利率支出。 |
| X折让 | 案例中未披露的浮动利率折让参数，决定Goodrich与Rabobank之间融资节省收益的分配。 |
| 年度保证费 | Morgan因承担双方信用风险和提供担保而收取的年度费用，示例中按本金0.1%计算。 |
| 信用风险 | 互换合约具有正市值时，交易对手违约可能导致守约方丧失有利合约价值并承担重置成本。 |
| 重置成本 | 原互换因违约终止后，按变化后的市场利率重新建立类似合约所产生的差额成本。 |
| 基差风险 | 互换两端参考利率、调整周期或付息频率不完全一致，导致浮动现金流无法完全抵消。 |
| ISDA主协议 | 场外衍生品市场用于约定终止条款、净额结算和双方权利义务的标准化合同框架。 |
| 中央清算 | 符合条件的衍生品交易由中央对手方承接履约安排，以降低双边交易对手风险。 |
| LIBOR | 案例发生时美元浮动融资常用的银行间拆借基准利率，其美元报价机制已于2023年终止。 |
| SOFR | LIBOR退出后美元利率市场使用的主要隔夜基准利率。 |
| OIS | 隔夜指数互换，课件引用BIS 2025年调查称其占全球场外利率衍生品成交额约65%。 |
| 资产负债管理 | 通过调整资产与负债的利率重定价特征，使二者现金流和风险暴露更加匹配。 |
| 总收益互换 | 一方支付某类资产收益并收取另一类资产收益，从而在不直接改变持仓的情况下转换经济风险暴露。 |
| 天气衍生品 | 以降雨、冰雹、积温等天气指标为标的的衍生工具，可用于对冲农业等行业面临的天气风险。 |
